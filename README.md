# Дожми сегодня

Локальное веб-приложение: загружает CSV со сделками, ранжирует их по прозрачным правилам и предлагает следующие действия. Нейросети и внешние API не используются; данные обрабатываются на компьютере, где запущено приложение.

## Запуск

Нужен Python 3.10 или новее. Дополнительные библиотеки устанавливать не надо.

### macOS

1. Откройте Terminal.
2. Перейдите в папку проекта. Если она распакована в Downloads, выполните `cd ~/Downloads/dozhmi_today`.
3. Запустите `python3 app.py`.

### Windows

Запустите `start_windows.bat`.

Браузер откроется автоматически. Если этого не произошло, перейдите на `http://127.0.0.1:8765`. Чтобы остановить приложение, нажмите `Ctrl+C` в окне Terminal.

## Использование

1. Выберите CSV-файл с выгрузкой сделок через поле слева. Встроенного примера нет.
2. Укажите дату расчёта и сумму, оставшуюся до плана.
3. Нажмите «Выбрать 5 сделок». Выбранные сделки появятся сверху цветными карточками; остальные останутся ниже бледно-серыми.

Поля CSV: `№`, `Клиент`, `Тип клиента`, `Товар`, `Сумма`, `Этап`, `Создана`, `Последний контакт`, `Следующий шаг (дата)`, `Комментарий менеджера`. Поддерживаются разделители запятая, точка с запятой и табуляция.

## Как работает приоритизация

Оплаченные, проигранные и явно отмеченные дубли исключаются из пятёрки. Правила учитывают сигналы в комментариях, даты следующего шага и сроков, свежесть контакта, сумму сделки и ограничения оплаты. Свободный текст распознаётся словарём регулярных выражений в `app.py`; если формулировка неизвестна, приложение показывает «не уверен».

Чтобы добавить новые варианты формулировок, расширьте `RULE_PATTERNS` в `app.py`.
